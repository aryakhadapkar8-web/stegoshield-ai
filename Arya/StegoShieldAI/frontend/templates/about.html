ABOUT STEGOSHIELD AI

Advanced Multi-Media Steganography & Data Privacy Cybersecurity Platform.

🎯 PROBLEM STATEMENT

Traditional cryptographic communication transmits encrypted ciphertext over public channels. While secure against decryption, the presence of encrypted traffic draws suspicion from network monitors and eavesdroppers. Furthermore, single-medium steganography systems lack flexibility across multi-media cover containers.

🚀 PROJECT OBJECTIVES

  • Develop a unified web platform for multi-media steganography (Image, Audio, Video, Text).
  • Integrate military-grade AES-256 GCM payload encryption with PBKDF2 key derivation.
  • Build real-time signal quality tools (PSNR, MSE, SSIM) to evaluate visual fidelity.
  • Implement automated capacity checking and AI steganalysis detection.

🔬 CORE ALGORITHMS & MATHEMATICAL MODELS

1. Least Significant Bit (LSB) Embedding

flat_pixels[:num_bits] = (flat_pixels[:num_bits] & 0xFE) | bits

Clears the 8th bit of pixel color bytes and performs bitwise OR with payload bit stream.

2. Peak Signal-to-Noise Ratio (PSNR)

PSNR = 10 * log10( (255^2) / MSE )

Measures image degradation in dB. Higher values (>40 dB) confirm imperceptible changes.
